# CJ Eletrica

Sistema visual estatico para gestao de uma empresa de eletrica.

## Tecnologias

- HTML5
- CSS3
- JavaScript puro
- Sem backend
- Sem banco de dados
- Sem autenticacao real

## Telas incluidas

- Dashboard
- Clientes
- Visitas Tecnicas
- Orcamentos
- Ordens de Servico
- Agenda
- Materiais
- Financeiro
- Manutencoes
- Relatorios
- Configuracoes

## Como abrir

Abra o arquivo `index.html` no navegador.

Os dados exibidos sao ficticios e servem apenas para demonstracao visual.
